# Personal Portfolio Website

Welcome to the repository of my personal portfolio website! As an aspiring **Machine Learning Engineer and Data Analyst**, I built this site to showcase my technical skills, academic journey, certifications, and real-world ML projects.

🔗 **Live Preview:** [Insert Link Here (e.g. GitHub Pages)]

## 🚀 Features
- **Dynamic Dark/Light Mode:** Integrated theme toggle that remembers user preferences via local storage.
- **Modern UI/UX:** Clean, sleek design with interactive hover effects and glassmorphism elements.
- **Fluid Animations:** Scroll-triggered fade-in animations and a unique, dynamically morphing profile picture shape using pure CSS keyframes.
- **Interactive Certifications:** A responsive grid displaying clickable, embedded PDF certificates.
- **Fully Responsive:** Optimized layout ensuring a beautiful experience across desktops, tablets, and mobile devices.

## 🛠️ Tech Stack
- **HTML5:** Semantic structuring and accessible layout.
- **CSS3:** Custom variables, flexbox, CSS Grid, and custom animations.
- **JavaScript (Vanilla):** DOM manipulation, smooth scrolling, intersection observers, and theme management.

## 📂 Sections
1. **Hero:** Morphing profile image and introduction.
2. **About:** Background and education (MCA focus).
3. **Skills:** Categorized technical expertise (Languages, Tools, ML Libraries, etc.).
4. **Projects:** Dedicated cards detailing ML, AI, and Data Analytics projects.
5. **Experience:** A timeline of roles including placements, events, and hackathons.
6. **Certifications:** Clean cards linking directly to my verifiable certificates.
7. **Contact:** Social links and direct email connections.
